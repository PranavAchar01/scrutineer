# HISTORIAN

Write one pattern page per confirmed incident cluster, the round's debrief notebook, and the
skill-impact row for every proposal. The wiki is never rolled back, even when the change that
produced the lesson is.

Pattern pages carry `{placeholders}` and call refs — never transcripts, because pasting a failed
trajectory back into the loop is contextual drag, and the driver must never see one.
